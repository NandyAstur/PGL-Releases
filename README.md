# PGL Releases - canal oficial de distribucion

Repositorio publico de distribucion de aplicaciones aprobadas de Petete & Geppetto Labs.

## Canales activos

### Petete Radio

- Windows: `windows.json`.
- Android: `android.json`.
- Las releases incluyen instalador o APK y su comprobacion SHA-256.

### Petete TV

- Android: `petetetv-android.json`.
- Catalogo Android: `petetetv-android-catalog.json`.
- Rutas de reproduccion: `petetetv-playback-master.json`.
- Windows: se incorporara mediante `petetetv-windows.json` cuando exista una release Windows verificada.

## Politica

Este repositorio contiene solamente binarios aprobados, manifiestos de actualizacion, hashes y datos publicos necesarios para el funcionamiento de las aplicaciones distribuidas.

El codigo fuente permanece en repositorios privados. No se publican aqui aplicaciones o proyectos que no tengan un canal de actualizacion verificado.

Las publicaciones se realizan localmente y cada manifiesto debe apuntar a una release del propio repositorio `NandyAstur/PGL-Releases`.
