# Instrucciones para agentes — PGL-Releases

Repositorio público de distribución oficial. Solo Petete Radio Windows y Android están autorizados actualmente. No modificar binarios, releases, hashes, manifiestos o canales de actualización sin autorización expresa. No introducir datos internos del repositorio privado de conocimiento. Preservar integridad y compatibilidad de actualizaciones.

Consultar las directrices centrales PGL cuando se disponga de acceso: https://github.com/NandyAstur/PGL-Knowledge/blob/main/directrices/DIRECTRICES_UNIVERSALES_PGL.md. No presumir lectura. Trabajar preferentemente en `main` respetando protecciones; no ejecutar GitHub Actions/CI/CD ni compilar en GitHub. No borrar historial ni material sin autorización. Informar de cambios, commits y comprobaciones reales; la publicación depende de decisión expresa del responsable.
